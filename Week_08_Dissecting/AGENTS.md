# Project guide

This project contains Week 08 coursework on manually inspecting a coding assistant and trying its configuration and extension features.

## Folder structure

- `Assignments/readme.md` gives the assignment overview and submission guidance.
- `Assignments/Task_1/` through `Assignments/Task_9/` each contain a Markdown task brief. Tasks 1 and 2 also include PNG images.
- `Assignments/Task_10_Bonus/Bonus_Task_10.md` describes the optional report and figure about your LLM workflow.

## Working instructions

- Work through the exercises yourself, using the coding assistant for support. Follow the `OUTPUT` section in each task brief.
- Keep assignment-related settings changes until the assignment is complete.
- For Task 9, redact API keys and other sensitive data from the submitted configuration. The remaining settings should match your screenshots.
- If your assistant lacks a required feature, follow the fallback in that task brief. Name the assistant and briefly explain the limitation and available alternatives.
